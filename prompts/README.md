# Prompts to try

Copy-paste prompt blocks for Muse, organized by the aiextracash.com guide that documents the workflow behind them. These are plain-text instructions you paste directly into Muse (app, web, or WhatsApp) — not verified third-party reports like the main use-case list one level up, and not (yet) a structured Skill/MCP format. See [Open questions](../README.md#open-questions--known-gaps) in the main README for why those are kept separate.

- [muse-shopify-paypal-checkout.md](muse-shopify-paypal-checkout.md) — shopping/checkout test prompts and a merchant self-test, from [Meta Muse Can Now Buy Through Shopify and PayPal](https://aiextracash.com/tools/muse/muse-shopify-paypal-checkout/).
- [muse-free-tier-business.md](muse-free-tier-business.md) — recurring-automation prompts (digest, triage, batch classification) that fit inside the ~100M weekly free tier, from [Muse Free-Tier Business Ideas](https://aiextracash.com/tools/muse/muse-free-tier-business-ideas/).

## Contributing

Same spirit as the main list: keep it practical, keep it something you've actually run. PRs adding a new prompt file should link back to the aiextracash.com guide it supports (or open an issue first if there's no guide yet) so the prompt has context, not just a bare instruction.
